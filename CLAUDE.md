# ТРАНСКОМ — Помощник МОП (Менеджер Отдела Продаж)

## О проекте
Веб-приложение для обучения и помощи менеджерам по продажам компании «Транском».
Два направления: **Вывоз снега** и **Асфальтирование/благоустройство**.

## Правила разработки

### Архитектура
- **Модульность**: каждый блок функциональности — отдельный файл
- **Данные отдельно от логики**: `js/data/` — только данные, `js/modules/` — только логика
- **Без фреймворков**: чистый HTML/CSS/JS, без сборщиков
- **Без npm/node**: приложение работает как статический сайт (открывается из файла или через простой HTTP-сервер)
- Подключение скриптов через `<script>` с атрибутом `type="module"` (ES Modules)

### Стиль кода
- Язык интерфейса: **русский**
- Комментарии в коде: на **русском**
- Имена переменных/функций: на **английском** (camelCase)
- CSS-классы: короткие, латиница (kebab-case или сокращения)
- Без jQuery, без внешних зависимостей

### Два режима работы
- **Снег** (snow) — вывоз снега: синяя тема
- **Асфальт** (asphalt) — дорожные работы: оранжевая тема
- Переключение меняет: скрипт, калькулятор, возражения, шпаргалку, чек-лист

### Вкладки приложения
1. **Новый клиент** — интерактивное дерево скрипта продаж
2. **Прозвон базы** — скрипт для звонков по существующей базе
3. **Калькулятор** — расчёт стоимости для клиента
4. **Возражения** — FAQ с поиском
5. **Шпаргалка** — быстрые подсказки менеджеру
6. **PlanFix** — настройки интеграции с CRM
7. **Обучение** — учебные материалы с квизами
8. **Тренажёр** — сценарии продаж + AI-клиент (Claude API)

### Интеграция с PlanFix
- REST API через Bearer-токен
- Настройки хранятся в localStorage
- Привязка к сделке → автосохранение чек-листа звонка
- Поддержка автолинковки через URL-параметры (для iframe)

### Контент и обучающие материалы
- **Продажные тексты (скрипты, возражения, шпаргалки)**: если информация уже есть в приложении — оставляем существующую версию, не переписываем. Тексты продаж проверены и согласованы.
- **Обучающие статьи и новые материалы**: Claude может добавлять полезную информацию, дополнять статьи, писать новые обучающие материалы, если знает тему. Цель — помочь менеджеру лучше разбираться в продукте и продажах.
- **Приоритет**: существующий контент продаж > новый контент от Claude. Новое добавляем, старое не трогаем.
- При создании статей для обучения — писать простым языком, с практическими примерами, с привязкой к работе менеджера Транском.
- **Изображения для статей**: к каждой новой статье генерировать уникальные изображения по смыслу через API генератора изображений. НЕ переиспользовать фото из других статей — каждая статья должна иметь свои уникальные иллюстрации.
- **Генерация изображений**: использовать API polza.ai, модель `nano-banana` (Gemini 2.5 Flash Image), размер `16:9`, **2.90₽/фото**. Именование: `learn_{article-slug}_{N}.jpg`. НЕ использовать dall-e-3 — качество плохое.

### Геймификация
- Уровни: Стажёр (0 XP) → Специалист (100) → Эксперт (300) → Мастер ДСР (600)
- XP: тест 80%=10XP, 100%=20XP, тренажёр=15XP, вопрос дня=5XP, серия 7дн=+20XP
- 10 бейджей-достижений, профиль менеджера в хедере
- Вопрос дня: случайный из пула при входе, серия дней

### Тренажёр продаж
- 6 сценариев: холодный звонок, «дорого», «есть подрядчик», секретарь, технология, после замера
- AI-тренажёр текст: Claude API (claude-haiku), 3 уровня сложности, автооценка по чек-листу
- AI-тренажёр голос: xAI Realtime API (grok-3), WebSocket + микрофон, живой голосовой разговор

### Хранение данных
- Настройки PlanFix: `localStorage` ключ `transkom_pf_settings`
- Прогресс обучения: `localStorage` ключ `transkom_learn_progress`
- Геймификация: `localStorage` ключ `transkom_gamification`
- API-ключ AI-тренажёра (Claude): `localStorage` ключ `transkom_ai_api_key`
- API-ключ голосового тренажёра (xAI): `localStorage` ключ `transkom_xai_api_key`
- Состояние чекбоксов: в памяти (сбрасывается при перезагрузке)
